# 默认呼吸冥想引导

- 音频：`breath-guide.zh-CN.mp3`，10 分钟，中文单声道。
- 文稿：`breath-guide-script.json`，本项目原创；段落之间保留练习时间，全程有低音量合成轻雨声，无背景音乐。
- 声音为 AI 合成，未使用第三方冥想录音或模仿特定真人。
- 女声：Microsoft Edge 中文神经语音 `zh-CN-XiaoxiaoNeural`，语速 -18%、音量 -8%，未更改音高。通过 edge-tts 合成原创文稿，再用 FFmpeg 编排；网站播放已生成的静态文件，不在使用者练习时调用外部服务。
- 按用户要求，开场叮声取自其提供录音的 3.4–8.7 秒片段，末尾淡出，不含其中的人声。原录音权利归原权利人；公开使用前需核实授权。轻雨声由程序合成，没有克隆参考录音中说话者的身份。
- 音频与文稿均不包含产品名称。
- 生成脚本：`scripts/generate-neural-guide.py`；产出元数据记录每段语音的真实起止时间。生成工具的代码许可不等同于语音服务的商业使用授权。

文稿是自然呼吸觉察引导，不要求深呼吸、放慢速度或屏息。四阶段脑动画是独立科普编排，语音不声称检测到了使用者走神。
